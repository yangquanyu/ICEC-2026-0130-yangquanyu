# 课题04：食堂/电梯高峰排队吞吐率建模 — 现场采样协议

## 点位（二选一，推荐 A）

- **A. 食堂高峰期窗口**：选一个高峰期明显排队的窗口（如快餐/麻辣烫档口），固定观测该窗口；
- **B. 教学楼电梯口**：选一部高峰期拥挤的电梯，观测其门口队列。

## 时段

- 午高峰 11:45–12:15 **或** 晚高峰 17:45–18:15，连续 30 分钟；
- 必须在真实高峰期，队列至少出现过 5 人以上，否则换点位重测。

## 记录规则（每 2 分钟一次，共 15 组）

到点后 30 秒内完成当次记录，字段如下（已做成 `raw_data_template.csv`）：

| 字段 | 含义 |
|---|---|
| 时刻 | HH:MM，到点即记 |
| 队列人数 | 当时正在排队的总人数（含正在被服务的人） |
| 本间隔到达人数 | 过去 2 分钟内新加入队列的人数 |
| 本间隔服务完成人数 | 过去 2 分钟内完成服务离开的人数 |
| 单次服务耗时秒 | 抽 1 位顾客用秒表计一次完整服务耗时 |
| 备注 | 突发情况（窗口暂停、插队、设备故障等） |

计数技巧：到达/完成人数用"正"字计数或 two-click 计数器，避免分心。

## 照片要求（大纲强制）

- **现场同框认证照**：本人 + 观测点位 + 手机（屏幕显示测量时间）同框，开始和结束各拍 1 张；
- 照片存入本目录 `photos/`，命名 `site_01.jpg`、`site_02.jpg`。

## 交付与分析

1. 填好的 `raw_data.csv`（即模板另存，15 组数据）；
2. 现场照片 2 张；
3. 运行分析脚本生成报告与图：
   ```bash
   python "01-Field-Discovery/课题04-排队吞吐率建模/analyze.py"
   ```
4. 根据报告中的瓶颈定位，手写 2–3 条**百元预算内**的工程改进方案，补进 `analysis_report.md` 的"改进方案"一节。
