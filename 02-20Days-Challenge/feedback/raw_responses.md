同学A
1. 有用吗？最想盯哪类？
学生端有价值。我最希望它盯的是需要学生“动手”的通知：选课、评奖评优、学籍异动、缴费、安全提醒、实习和毕业环节。这类漏一条就是事故，比十条讲座通知重要得多。
2. 标题 + 日期 + 链接够不够？
对“看”够，对“办”远远不够。至少要有：截止时间、发布单位、涉及对象（年级、专业）、是否需提交材料。另外强烈建议区分“新增”和“更正”：更正通知比新通知更容易被漏，学生按旧版本办就麻烦了。
3. 会天天看吗？
会，但必须固定时间（早 8 点前）。而且当天没有新增就明确写“今日无新增”，别发一份空壳日报，容易让人以为程序坏了。顺便说一句，你这份只扫描了 1 个页面，如果教务、学院、就业网是分开挂的，那就一定会漏。
不想看的情况：抓取不全或把旧通知当新的、摘要失真导致误读、推送太碎。

同学B
1. 这份日报有用吗？最想盯哪类通知？

有用，但价值取决于「准」和「全」，不在于每天都有。我最想让它盯的是有硬截止时间的：

选课/教务通知 —— 窗口期短，错过就没法补，这是第一优先级
考试安排（四六级、期末、考研报名）​ —— 同样错过代价大
奖助学金/资助申请 —— 材料截止时间容易漏看
招聘宣讲/实习 —— 时效性强
相对不需要盯的是日常活动宣传、社团招新这类，扫一眼就行。

2. 格式够用吗？还缺什么？

「标题 + 日期 + 链接」骨架可以，但缺了两个关键字段：

截止日期 / 关键时间点（最重要，应该按它排序，而不是按发布日期）
发布单位（我要靠它判断跟不跟我相关，是全校、本院还是某个社团）
另外建议加：分类标签（考试/选课/奖助/招聘）、「新增 / 有更新 / 即将截止」的状态标记，以及一两句摘要——不用点链接就知道讲什么。

3. 会不会天天看？什么情况下不想看？

不会天天看。理想模式是「有事才推，无事静默」——样例里「本次运行没有新增通知」这种日报，其实没必要每天发一份。

会让我不想看的情况：

没新增还天天发，形成噪音，迟早免打扰
大量跟我无关的通知混进来
同一条通知反复推
周末/假期打扰，或者标题看不出重点
一句话建议：把它从「每日汇总」改成「变化提醒 + 截止日清单」，价值会高很多——只在有新增或临近截止时出现，其余时间安静。

同学E
1. 有用吗？最想盯哪类？
有用，但对我这种人不该做成“日报”，该做成“告警”，因为本科生那些事跟我没关系。我最想让它盯四类：学位环节的时间节点（开题、中期、预答辩、送审、答辩申请，尤其送审的截止时间一变就是延毕）、学术讲座和 seminar 报名、实验室相关（安全培训、仪器预约、门禁权限）、助研津贴和报销口径变化。这几类都散在研究生院、学位办、学院和实验室四个地方，我自己最容易漏的就是学位办那一块。

2. 标题 + 日期 + 链接够不够？
不够，而且我认为最关键的字段你还没列出来：附件。研究生通知的正文经常是废话，真正有用的是那几个 doc 和 xlsx（评审表、模板、汇总表），没有附件我得点进去再翻一遍，那我为什么不直接看原文。另外还缺通知层级（校级、院级还是系级，口径可能互相矛盾）、是否长期有效（有些是常年有效的规定，不该混进“今日新增”）、变更记录（地点和时间改过一次的通知，按旧版去就白跑）。

3. 会天天看吗？
不会天天看，一周两三次顶多了。更希望的是关键词订阅加上只在命中时才推，别每天准点给我一份清单。
不想看的情况：① 本科生活动、校园歌手赛、招聘会（对我没用，占了 80% 我很快就不看了）；② 0 条新增还照发；③ 只有标题没有附件的“半个通知”；④ 也是我最在意的，只扫一个页面。通知还散在公众号和年级群里，你少扫一个源，我照样得自己刷群，那这个工具就没省我的事。
