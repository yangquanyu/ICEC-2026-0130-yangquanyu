# v1.0.0 — 首个可用版本（2026-11-16）

## 改动内容

- 实现 `notice_watcher.py`：定时抓取校园通知页面，启发式识别通知链接，生成新增日报
- 实现遥测日志：每次运行向 `process_logs/` 追加 JSONL 记录（时间戳、耗时、抓取数、报错）
- 新增 `config.json`：目标页面、关键词、超时等配置外置
- 新增 `--dry-run` 试跑模式：不更新状态、不写日报，用于改配置后验证
- 编码处理：依次尝试响应声明编码 → UTF-8 → GB18030，覆盖国内高校常见 GBK 页面

## 背景与目标

阶段一选题为课题 04（排队吞吐率建模）与课题 10（数字任务耗时审计）；阶段二选题为项目四（校园实用程序 + 7 天运行日志）。本仓库 11/16 建仓，本版本为目标"11/16 当晚产出第一条成功遥测记录"的最小可用实现。
