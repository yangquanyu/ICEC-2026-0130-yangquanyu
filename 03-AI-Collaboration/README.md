# 03-AI-Collaboration — 关键 AI 提问排障对话记录

本目录记录项目四（notice_watcher）与课题 10 实验过程中，借助大模型排障的关键案例。
每条记录包含：问题现象 → 提问方式 → AI 诊断路径 → 根因 → 修复 → 验证结果。

| 案例 | 问题 | 结果 |
|---|---|---|
| [01](01-breadcrumb-parser-bug.md) | 解析器漏掉列表第一条通知（19/20） | 定位为面包屑导航状态污染，修复后 20/20 |
| [02](02-report-formatting-bug.md) | 分析报告表格 4 行漏格式化参数 | 提交前自查发现，删除"打补丁"式修正 |
| [03](03-gbk-encoding.md) | Excel 保存的 CSV 读取乱码 | GBK → UTF-8 BOM 转换，值不变 |
| [04](04-category-taxonomy.md) | 人工与脚本的"类别"字段不可比 | 统一为固定主题词表 |

排障方法说明：所有案例遵循同一模式——**先用遥测日志/输出定位现象，再向 AI 描述"预期 vs 实际"+ 相关代码片段，要求给出根因假设和验证方法，最后自己写验证**。AI 提供假设，实测数据做裁决，不直接采信未经验证的结论。
